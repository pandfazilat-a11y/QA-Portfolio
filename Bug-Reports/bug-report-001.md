# BUG-001: Кнопка «Регистрация» не работает

**Title:** Кнопка «Регистрация» не отправляет форму

**Environment:**

* Browser: Google Chrome
* OS: Windows 11

**Preconditions:**

* Пользователь находится на странице регистрации.
* Все обязательные поля заполнены корректными данными.

**Steps to Reproduce:**

1. Открыть страницу регистрации.
2. Ввести имя.
3. Ввести корректный email.
4. Ввести корректный пароль.
5. Нажать кнопку «Регистрация».

**Expected Result:**
Пользователь успешно регистрируется и переходит в личный кабинет.

**Actual Result:**
После нажатия кнопки «Регистрация» ничего не происходит, пользователь остаётся на странице регистрации.

**Severity:** Medium

**Priority:** High
