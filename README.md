# Test Cases

## TC-001: Регистрация пользователя

**Title:** Проверка регистрации нового пользователя

**Preconditions:**
- Пользователь находится на странице регистрации

**Steps:**
1. Открыть страницу регистрации
2. Ввести имя
3. Ввести email
4. Ввести пароль
5. Нажать кнопку "Регистрация"

**Expected Result:**
Пользователь успешно зарегистрирован


## TC-002: Вход в аккаунт

**Title:** Проверка авторизации пользователя

**Preconditions:**
- Пользователь имеет зарегистрированный аккаунт

**Steps:**
1. Открыть страницу входа
2. Ввести email
3. Ввести пароль
4. Нажать кнопку "Войти"

**Expected Result:**
Пользователь успешно вошёл в аккаунт


## TC-003: Поиск товара

**Title:** Проверка поиска товара

**Steps:**
1. Открыть интернет-магазин
2. Ввести название товара в поиск
3. Нажать кнопку поиска

**Expected Result:**
Отображаются подходящие товары
